## Public-source boundary

This repository contains only publishable portfolio material. Confidential employer references, internal reports, proprietary implementation details, private contact data, and earlier resume artifacts are local evidence sources and must never enter Git history.

The repository boundary is enforced by defensive ignore rules and `scripts/check-public-boundary.sh`. Professional case-study claims and visuals also require a manual disclosure review before publication.
